# Project Flora

Landing page romântica e comemorativa criada por **Ederson** para **Flora**.

Experiência digital em Português de Angola (`pt-AO`), com identidade visual **Midnight Romance**, preparada para publicação futura via GitHub Pages.

---

## Estado do projeto

| Fase | Descrição | Estado |
| ---- | --------- | ------ |
| 1 | Planeamento e estrutura | Decisões estabelecidas |
| 2 | Desenvolvimento visual | Concluída |
| 3 | Interações e motion (revelação da carta) | Implementada |
| 4 | Testes e publicação | Pendente |

---

## Stack

- HTML5 semântico
- CSS3 (mobile-first)
- JavaScript vanilla (preparado; interações na Fase 3)
- SVG
- Git / GitHub Pages (publicação futura)

Sem frameworks, backend ou bases de dados.

## Como visualizar localmente

```bash

```

Abrir `http://localhost:8080` no navegador.
